# Datum Collective Website

The official public website for Datum Collective, presenting the collective, its projects, research, engineering work, members, and development across epochs.

## Status

**Initial planning**

## Project Lead

**Agrajeet Sharma**

## Objective

Build a minimal, technically focused public website that represents Datum Collective and provides a central place to present its projects, research, engineering work, and development.

The website should communicate what Datum is and what we build without presenting the collective as a conventional startup or commercial organisation.

## Design Direction

The website should follow Datum's established **ASCII, minimalist, technical aesthetic**.

The visual language should favour:

- Monospaced typography
- ASCII and text-based visual elements
- Minimal colour
- High contrast
- Generous whitespace
- Simple geometric layouts
- Restrained, information-focused interfaces
- Minimal decorative UI

The site should feel technical and deliberate rather than polished in a conventional corporate or startup style.

### Reference

Our current primary visual reference is:

https://ertdfgcvb.xyz/

The reference is intended to communicate the visual language and interaction philosophy, not to be reproduced directly.

The final design should remain distinctly **Datum**.

## Scope

The initial website is expected to include:

- **Home** — Introduction to Datum Collective
- **About** — Purpose, philosophy, and structure
- **Projects** — Current and completed projects
- **Research** — Research work and technical outputs
- **Members** — Current members and their roles
- **Epochs** — Historical record of Datum's development
- **Contact** — Appropriate channels for reaching Datum

The information architecture may change during development.
